Get Started With Minecraft

Before You Start

The Java edition of Minecraft and an @andrew.cmu.edu or @alumni.cmu.edu account are required to sign in to the CMU Minecraft server. If you need an @alumni.cmu.edu email, follow these instructions.

The Server's Address

mc.andrew.cmu.edu

Connect in 10 Steps

  1. Open Minecraft and press Play.
  2. Select Multiplayer.
  3. Add a new server.
  4. Add the server information. Name it CMU, and for the address, enter mc.andrew.cmu.edu.
  5. Click on the CMU server.
  6. Go to the auth address and give your code. The server shows a code that's good for 20 minutes. Enter it at minecraft.alumni.cmu.edu/auth.
  7. Link your CMU and Minecraft accounts. Only one Minecraft account can be linked to each Andrew ID.
  8. See the confirmation message.
  9. Click Back to Server List.
  10. Click on the CMU server again. You're in.
