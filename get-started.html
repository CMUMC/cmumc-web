0. Before you start

The Java edition of Minecraft and an @andrew.cmu.edu or @alumni.cmu.edu account are required to login to the CMU Minecraft server. If you need an @alumni.cmu.edu email, please follow these instructions.

1. Open Minecraft and Press Play

2. Select Multiplayer

3. Add a New Server

mc.andrew.cmu.edu

4. Add the Server Information

5. Click on the CMU Server

6. Go to the Auth URL and provide your code

https://minecraft.alumni.cmu.edu/auth

7. Link Your CMU and Minecraft Accounts

8. Confirmation Message

9. Click "Back to Server List"

10. Click on the CMU Server
